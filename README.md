# English Overdrive v0.2.4 — Toolkit Coherence

PWA mobile-first para preparação intensiva de TOEIC e inglês profissional.

## Novidades desta versão
- Unifica a experiência visual do **Thinking Toolkit** com o **Active Vocabulary**.
- Toolkit agora usa o mesmo modelo de learning card: tags, expressão em destaque, significado, áudio, exemplo, produção ativa, ação principal e navegação.
- Adiciona filtro por **Nível de prioridade**: Core, Pro e Advanced.
- Adiciona filtro por **Contexto**: Reuniões, Apresentações, Entrevistas, Análise & Dados, Estratégia, Negociação, Liderança, Problemas & Decisões, Comunicação executiva e Operações.
- Mantém o filtro por **Função mental**, agora como terceira dimensão de descoberta.
- Contextos são combináveis com nível, função e busca.
- Adiciona controle de velocidade do áudio diretamente no Toolkit, compartilhando a preferência do Active Vocabulary.
- Adiciona bloco **Produza sem traduzir** também aos atalhos mentais.
- Mantém scroll horizontal por gesto para todos os filtros no mobile.
- Estrutura flat: todos os arquivos permanecem na raiz para facilitar upload pelo celular ao GitHub.
